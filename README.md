# Tokyo Open Data

東京都や都内自治体が公開するオープンデータを調査し、取得・整理・活用するためのプロジェクトです。

## 進め方

- 作業単位は GitHub Issue にする
- 優先順位と進捗は GitHub Projects で管理する
- データごとに出典、ライセンス、取得日を記録する
- 大きな元データは原則として Git に直接コミットせず、取得手順をコード化する

## Project のステータス

- Backlog: 候補や未整理のタスク
- Ready: 次に着手できるタスク
- In progress: 作業中
- Done: 完了

## はじめに

最初のタスクは、このリポジトリの GitHub Project を参照してください。
