# Product Overview

## Background / Problem

帰国予定だった短期滞在者が母国の戦争、政変、迫害、大規模混乱等によって帰国困難になったとき、情報は入管、教育、医療、自治体、支援団体に分散します。しかし本人が必要とするのは制度一覧ではなく「今日何をするか」です。

## Product

StayBridge Tokyo は、最小限の Situation Check を時間軸の Personal Roadmap と地域の Local Action に変換するWebアプリです。公式情報で確認事項を示し、Open Dataで近隣の学校・医療・子育て・公共資源を表示します。

## Target / Persona

短期の旅行・親族訪問等で東京に滞在し、生活基盤を持たない外国人と子ども連れ家族が中心です。主デモはミャンマー国籍の架空 Persona A。詳しくは [persona.md](persona.md)。

## Before / After

Before: 検索語も制度名も分からず、分散したサイトを往復する。  
After: 回答に基づき TODAY、THIS WEEK、NEXT 30 DAYS、期限前、LOCAL ACTION の順に確認できる。

## Value and Vision

利用者には「自分の周りの次の一歩」を、行政には「どこで支援準備を確認するか」を提供する。将来は匿名化・集計された利用傾向を、必要なデータ整備の検討に活かす。ただしMVPは個人追跡や需要推計をしない。
