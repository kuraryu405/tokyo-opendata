# Persona

## Persona A（仮想Persona）

以下は設計・デモ用の**架空の人物**であり、実在人物・個別ケース・法的評価ではありません。

|項目|内容|
|---|---|
|年齢|34歳（性別に依存しない設計）|
|国籍|ミャンマー|
|同行者|6歳の娘1人|
|言語|日本語は初級、簡単な英語は可能|
|来日目的|旅行または知人訪問|
|元の予定|約2週間の短期滞在、30日以内に帰国予定|
|基盤|日本での職業、恒常的住居、学校登録、生活圏がない|

滞在中に母国情勢が急変し、予定どおり帰国することが難しくなった。ホテル等の一時滞在先、子どもの生活・教育、医療、生活費、相談先が不安である。開始時の問いは「私は今、何をすればいい？」であり、在留制度名の検索ではない。

設計上は氏名、旅券番号、正確な住所、政治的立場、宗教、迫害内容を尋ねない。帰国困難は本人の現在認識であり、法的な認定ではない。
