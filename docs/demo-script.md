# 2-minute Demo Script

**0:00–0:20 — Persona** 34歳の架空の母親が6歳の娘と東京へ旅行に来た。2週間後に帰国予定だったが、滞在中の母国情勢の変化で帰国が難しくなった。問いは「私は、明日からどうすればいい？」。

**0:20–0:35 — Problem** 支援情報は存在するが、入管・教育・医療ごとに分かれている。本人は制度名ではなく次の行動を必要としている。

**0:35–1:15 — User demo** 英語を選び、Persona Aを読み込む。Situation Check後、TODAYの「滞在について公式に確認」、THIS WEEKの専門相談と教育相談、NEXT 30 DAYSの医療・生活を表示する。「なぜこの案内？」で回答とルールを示す。Local Actionで学校・医療等のOpen Data由来の地域資源を見せ、利用可否は確認が必要と伝える。

**1:15–1:35 — Open Data / admin** Crisis Support ViewでMVPの固定対象（北区・Myanmar）を確認する。人口参考データ、既存資源、短期滞在者を完全には捉えないData Gap、対応検討項目を表示する。

**1:35–1:50 — Safety** AIには在留や就労を決めさせない。「その他」の自由記述は許可済みカードの追加選定だけに使い、公式情報、決定論的Rule Engine、Human Handoffを組み合わせる。

**1:50–2:00 — Closing** StayBridge Tokyo は新制度ではない。既存の情報を、その人が東京で動ける「次の一歩」へ変える。
