# Limitations

- 自治体の外国人人口統計は中長期居住者等の参考であり、短期滞在者・旅行者・帰国困難者を完全には反映しない（population coverage gap）。
- 施設数は、空き、受入条件、対応言語、費用、診療・相談・教育の可否、処理能力を示さない。
- Open Dataの更新頻度、網羅性、地理情報、言語情報は提供元により異なる。実装のSource Registry metadataを確認する。
- Persona AとSituation回答はデモfixtureであり、実在人物・個別ケースを表さない。施設・人口は公式ソース由来の非全件キャッシュであり、網羅性・現在の利用可能性を保証しない。
- 日本語・英語・ミャンマー語は静的な翻訳モックで、LLM/APIは未接続。とくにミャンマー語は公開前の専門家レビューが必要。
- 日本語・英語以外の翻訳品質や制度説明には専門家レビューが必要となる場合がある。
- StayBridge Tokyo は法律、在留、難民・補完的保護、就労、就学、給付、危険度を判定しない。
- MVPは一部自治体・カテゴリのみの対応で、全国網羅、リアルタイム危機検知、支援能力の把握、個人需要の追跡を行わない。
- Crisis Viewの任意回答集計は、同意済みSituation Check回答の観測範囲だけであり、回答しない人を含む母集団を代表しない。人口、需要不足、優先度、サービス提供能力は推定しない。
- 集計は自治体13117、東京暦の直近7/30/90日、1軸のみで、全体・カテゴリとも5件未満を非表示にする。最終更新はJST日付へ粗視化し、7東京暦日を超えるとstaleと示す。会話・個票は入力にも出力にも使わない。
